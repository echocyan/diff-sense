# 确定性层 × Agent 混合架构 (Deterministic × Agent Hybrid)

将审查流水线拆分为确定性层（差异解析、文件过滤、规则匹配、行号锚定、输出格式化）和 Agent 层（通过 AI SDK 的 ToolLoopAgent 实现 LLM 工具调用循环）。确定性层是行为可预测的纯函数；Agent 层处理需要 LLM 推理的主观判断。

另一种方案是纯 LLM 方式——把完整差异直接丢给 LLM 并解析其响应。这更简单，但文件筛选不可靠、输出结构不一致、且在无关文件上浪费 token。混合方式让我们在过滤和锚定上保证正确性，同时把困难的部分（发现真正的缺陷）留给 LLM。这一模式已被 alibaba/open-code-review 验证，该项目在 Go 中采用了相同的拆分。

## 备选方案 (Considered Options)

- **纯 LLM (Pure LLM)**：把所有内容发送给模型，解析自由文本输出。更简单，但过滤、锚定和输出格式化不可靠。
- **纯确定性 / 静态分析 (Pure Deterministic)**：仅用模式匹配规则，不用 LLM。可靠但只能发现已知模式，无法推理意图或跨文件关系。
- **混合方式（选定）(Hybrid, chosen)**：能用规则决定的交给确定性层，需要判断的交给 Agent。构建更复杂，但在该可靠的地方可靠，在规则不够的地方有智能。
